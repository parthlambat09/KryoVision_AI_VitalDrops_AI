## 🚀 The Core Problem & Our Impact
Over 30% of perishable agricultural produce in India spoils before reaching consumers due to erratic reefer failures and fragmented logs, causing a ₹1.5+ Lakh Crore annual economic loss. 

**KryoVision transforms reactive logistics into a self-monitoring, self-correcting ecosystem.** By bridging physical road logistics with Explainable AI (XAI) and edge IoT, we protect farmer livelihoods and guarantee transparent supply chains.

<br>

## ⚙️ Platform Features

| Feature | Description | Tech Stack |
| :--- | :--- | :--- |
| 🦠 **Optical Bio-Surveillance** | CNN-powered edge detection of *Botrytis* fungal spores before visible rot. | `PyTorch`, `OpenCV` |
| ⏳ **Kinetic RSL Engine** | Dynamic Remaining Shelf Life (RSL) calculation based on thermal abuse telemetry. | `Python`, `Scikit-Learn` |
| 🗺️ **Autonomous Rerouting** | Automatically redirects failing reefers to the nearest cold hub if thresholds are breached. | `FastAPI`, `Mapbox GL` |
| ⚖️ **GenAI Dispute Arbiter** | Parses IoT logs and SLA contracts to output transparent, insurance-ready PDF claim dockets. | `LangChain`, `Gemini` |
| 📱 **Offline-First PWA** | Allows drivers to log pre-cooling checkpoints in rural areas without cellular networks. | `React`, `Service Workers` |
